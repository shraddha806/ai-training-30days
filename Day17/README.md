# Day 17 — Agentic AI Business Use Cases

## What this folder is for

This module compares **traditional chatbots** (mostly Q&A and scripted replies) with **agentic AI** (models that plan, call tools, branch on outcomes, and complete multi-step workflows with guardrails).

## Deliverables (complete)

| Deliverable | File | Contents |
|-------------|------|----------|
| Written use cases (3) | [assignment.md](assignment.md) | Full descriptions: business task, why agentic wins, tools, decision steps |
| Agent flow diagram | [flow_diagram.txt](flow_diagram.txt) | ASCII diagram of the agent loop and tool interactions |

## How to use

1. Read **assignment.md** for the three scenarios and the closing observation.
2. Open **flow_diagram.txt** in a monospace font to view the flow diagram.

## The three use cases

1. **HR leave management** — balance checks, validation, approvals, system updates, notifications.  
2. **Customer support ticket resolution** — triage, CRM/knowledge retrieval, resolution path, ticket updates.  
3. **Sales lead qualification** — enrichment, scoring, scheduling, CRM updates.

Each use case in `assignment.md` explains *what* the business needs, *which systems* the agent touches, and *how* decisions branch step by step.
